# SPLAT!

Браузерная 2D-стратегия с видом сверху: синие Сплаты против красной фракции. Игрок рисует построения, разделяет и объединяет отряды, распределяет их по просторной арене и окрашивает территорию. Тактический выбор — охват поля или концентрация сил. Ориентир партии — 3–5 минут, не SLA.

Документация этапа **S−1 (Bootstrap) принята пользователем 05.11.2026**. S0–S7 имеют статус `not_started`; S0 начинается только по отдельному поручению в новом чате. Приложение, игровой код, зависимости, сборка и URL пока отсутствуют. В каталоге нет `.git`, ветки и коммитов; GitHub/Vercel не подключались. Факты и передача — в [STATUS](docs/STATUS.md), результаты аудита — в [BOOTSTRAP_REPORT](docs/BOOTSTRAP_REPORT.md).

Рабочий каталог `GenAI_SPLAT` уже является корнем проекта: вложенный `splat/` создавать не требуется. Исходный файл `SPLAT_CODEX_MASTER_TZ_v3.md` перенесён без изменений в [MASTER_SPEC](docs/MASTER_SPEC.md). Исходные `visual_references/` сохранены; копии двух изображений и ограничения использования находятся в [каталоге референсов](docs/design/references/README.md).

После приёмки S−1 откройте новый чат в этом каталоге и поручите: «Прочитай AGENTS.md, docs/STATUS.md и обязательные документы; проверь фактическое состояние. Реализуй только S0 из docs/PLAN.md. Соблюдай MASTER_SPEC, архитектуру и дизайн. После проверок дай чеклист ручной приёмки и остановись». Подключение внешних аккаунтов, remote, push/merge и деплой выполняются только в пределах отдельного разрешения.

**Команды после S0:** когда появятся `package.json` и lockfile, план предусматривает `npm ci`, `npm run dev`, `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`, `npm run preview`, `npm run format`. Сейчас этих скриптов нет; команды не запускались. S0 должен описать точные команды smoke-проверок и фактические результаты. Статический output — `dist/`; Vercel preview относится к S0, production-релиз — к S7 и отдельному разрешению.

MVP: одна вручную созданная карта, один полный тактический цикл, B-static синие/красные юниты, минимальный HUD без логотипа, обучение, Pause/Restart и итоги. Runtime GenAI, backend, API, БД, React, мультиплеер, экономика, генерация карт и жидкостная физика исключены. Полные ограничения и утверждённые решения остаются в мастер-ТЗ; числовой баланс и спорные способы управления требуют проверки по этапам.
