# SPLAT!

SPLAT! — браузерная тактическая 2D-стратегия о противостоянии синих и красных сгустков краски. Игрок рисует построения, управляет несколькими отрядами и продвигается вправо, выбирая между концентрацией сил и обходом противника. В игре три уровня: «Два прохода», «Излучина» и «Редуты».

## Как играть

Выберите синюю группу нажатием на неё. Зажмите левую кнопку мыши и нарисуйте линию, чтобы задать построение; клик по свободному месту перемещает выбранную группу с сохранением её текущего расположения. Клик по другой синей группе переключает управление. Красные группы не выбираются.

- **X / «Разделить»** — разделить выбранный отряд поровну.
- **M / «Объединить»** — включить режим объединения и выбрать вторую синюю группу.
- **R / «Пополнить»** — потратить 5 ресурса и добавить до двух бойцов в выбранную группу, максимум 40 синих на поле. Обычный красный приносит 1 ресурс, девиант — 7.
- Стрелки камеры перелистывают карту; камера также следует за выбранным отрядом. Очередной участок открывается после захвата рубежа.
- **«Как играть»** открывает интерактивное обучение; **«Меню»** позволяет перезапустить партию или выбрать уровень.

Для победы последовательно захватите промежуточные рубежи и конечную точку. Захваченные рубежи сохраняются до конца партии; конечная точка должна принадлежать синим в момент победы. Показатель окрашенной территории информационный. При потере всех синих наступает поражение.

Вода и стены непроходимы. Квадратные области замедляют, мины ранят синих и перекрашивают близлежащие клетки, пушки вращаются и непрерывно стреляют. Девианты сильнее обычных красных. Текущая версия продукта и все пункты плана приняты заказчиком 11.11.2026.

## Запуск

Нужны Node.js **24.x** и npm. В корне репозитория:

```sh
npm ci
npm run dev
```

Откройте адрес, выведенный Vite, обычно `http://127.0.0.1:5173/`. Для просмотра production-сборки локально:

```sh
npm run build
npm run preview
```

## Архитектура

Игра работает целиком в браузере: TypeScript strict, PixiJS для игрового поля, HTML/CSS для интерфейса и Vite для статической сборки. Сервер игры, база данных и runtime-вызовы генеративного ИИ не используются.

```text
Указатель и клавиатура → команды → детерминированная симуляция
                                      ↓
                               неизменяемый snapshot
                                      ↓
                              PixiJS и HTML/CSS HUD
```

Симуляция отделена от DOM и рендера. Она работает с фиксированным шагом времени, начальным seed и журналом команд; повтор команд позволяет воспроизвести состояние партии. Рендер читает snapshot и не меняет игровое состояние. Контроллер красных детерминированно выбирает цели и отдаёт команды отрядам. Статичные безликие маркеры сохраняют визуальное правило B-static.

Основные каталоги:

| Путь | Назначение |
| --- | --- |
| `src/core/` | Типы, конфигурация, построения, часы и вспомогательные функции |
| `src/simulation/` | Состояние, движение, бой, окраска, цели, опасности, split/merge и инварианты |
| `src/enemy/` | Контроллер красных отрядов и девиантов |
| `src/input/`, `src/app/` | Обработка ввода, команды и управление сессией |
| `src/rendering/`, `src/ui/` | PixiJS-рендер, камера, HUD и обучение |
| `src/levels/` | Каталог уровней и их типизированные конфигурации |
| `tests/unit/`, `tests/smoke/` | Модельные и браузерные проверки |
| `docs/` | Спецификация, решения, план, результаты и история |

Новый встроенный уровень задаётся конфигурацией `LevelConfig` и записью в `src/levels/catalog.ts`: размеры мира, сетка, препятствия, последовательные рубежи, финальная точка, посты врагов и опасности. Игрового редактора или импорта пользовательских карт пока нет. При добавлении уровня нужно проверить проходы, позиции отрядов, все варианты мин, границы камеры, достижимость целей, replay и баланс.

## Проверки

```sh
npm run typecheck
npm run lint
npm run test
npm run format:check
npm run build
PLAYWRIGHT_CHANNEL=chrome npm run test:smoke
```

Браузерные smoke-тесты используют локальную сборку `dist`; сначала выполните build. Для Playwright Chromium вместо установленного Chrome можно установить его командой `npx playwright install chromium`. Проверки, создающие `reports` или `test-results`, запускайте во временной копии, чтобы сохранить существующие результаты.

Последние проверенные локально изменения баланса «Редутов»: 178 unit/integration-тестов, обе проверки типов, lint, форматирование, сборка и четыре Chrome-сценария, включая полные партии трёх уровней. Детали и ограничения — в [отчёте о балансе](docs/REDOUBTS_BALANCE_REPORT.md). Автоматические проверки не заменяют ручную оценку игры; Firefox, WebGPU, FPS и полный проигрыш через UI для этого среза не проверялись.
