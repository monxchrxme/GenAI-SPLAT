## Локальный запуск

Нужен **Node.js 24.x**; проверено на **24.22.2 / npm 11.19.1**. Версия указана в `.node-version`, все прямые зависимости точные, транзитивные зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Открыть адрес из терминала (обычно `http://127.0.0.1:5173/`). ЛКМ по синему маркеру или небольшому промежутку плотной группы выбирает её. Зажать ЛКМ и нарисовать линию; release задаёт форму с 40 равномерными слотами. Пока идёт движение, можно рисовать новую цель. Esc отменяет только текущий черновик; клик по свободному месту направляет выбранную группу туда, сохраняя текущее расположение; клик по другой группе переключает выбор, «Заново» создаёт чистую сессию (также Tab + Enter/Space). Resize сохраняет world/принятый приказ; текущий черновик отменяется. Растянутая цель временно подсвечивается с текстом натяжения, без auto-split. Финальные спрайты — S6. Демо статической сборки: `http://127.0.0.1:4173/` (`npm run preview -- --port 4173 --strictPort`).

В этой среде Node/npm не были установлены в PATH. Для немедленного запуска можно использовать уже подготовленный временный runtime:

```sh
export PATH=/private/tmp/node-v24.22.2-darwin-arm64/bin:$PATH
npm run dev
```

`/private/tmp` может быть очищен системой; для постоянной работы установите Node.js 24 LTS обычным для вашей системы способом. Скачать зависимости и открыть локальный порт в песочнице удалось только с разрешённой эскалацией.

## Проверки и статическая сборка

```sh
npm run typecheck
npm run lint
npm run test
npm run format:check
npm run build
npm run test:smoke
```

Smoke запускает `dist/` через `npm run preview -- --port 4173 --strictPort`, поэтому сначала нужен build. По умолчанию используется Playwright Chromium; если его нет, установите `npx playwright install chromium` либо используйте установленный Chrome:

```sh
PLAYWRIGHT_CHANNEL=chrome npm run test:smoke
```

В действии 6 прошли 80 unit/integration и 15 Chrome smoke, включая QA-01/QA-07, регрессию S0, DPR 1/2, быстрые развороты/отмены, resize и чистый Restart. Typecheck/lint/format:check/build также прошли. [Команды, результаты и ограничения](docs/S1_REPORT.md). `npm run format` форматирует код/конфиги; Markdown и референсы исключены из автоформатирования. `npm run test:watch` включает watch-режим. Сборка в dist локальная и не означает публикацию.
