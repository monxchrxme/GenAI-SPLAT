# SPLAT!

Браузерная 2D-стратегия с видом сверху: синие Сплаты против красной фракции. Игрок рисует построения, разделяет и объединяет отряды, распределяет их по просторной арене и окрашивает территорию. Тактический выбор — охват поля или концентрация сил. Ориентир партии — 3–5 минут, не SLA.

**S0 принят пользователем 06.11.2026**, S−1 — 05.11.2026. На поле — 40 неподвижных синих маркеров в одной группе; «Заново» создаёт чистую сессию. Пользователь опубликовал и проверил [Vercel Preview](https://genai-splat-dqhs48lqm-great-chr.vercel.app/); агент подтвердил READY/Preview и SHA, повторил локальные проверки. Принятый source commit — `29946cdefb1208c93b61303ed2fcd8dc984cbee1`. Для S1 выполнено только действие 0: сохранены документы и подготовлена локальная ветка; игровая реализация S1–S7 не начата. [Приёмка, статистика и доказательства](docs/S0_ACCEPTANCE.md), [статус и handoff](docs/STATUS.md), [исходный отчёт S0](docs/S0_REPORT.md).

## Локальный запуск

Нужен **Node.js 24.x**; проверено на **24.22.2 / npm 11.19.1**. Версия указана в `.node-version`, все прямые зависимости точные, транзитивные зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Открыть адрес из терминала (обычно `http://127.0.0.1:5173/`). Единственное действие S0 — кнопка **«Заново»**, также доступная через Tab и Enter/Space. Resize вписывает весь мир без изменения его логических размеров. Маркеры намеренно не двигаются; финальные спрайты относятся к S6.

В этой среде Node/npm не были установлены в PATH. Для немедленного запуска можно использовать уже подготовленный временный runtime:

```sh
export PATH=/private/tmp/node-v24.22.2-darwin-arm64/bin:$PATH
npm run dev
```

`/private/tmp` может быть очищен системой; для постоянной работы установите Node.js 24 LTS обычным для вашей системы способом. Скачать зависимости и открыть локальный порт в песочнице удалось только с разрешённой эскалацией.

## Проверки и статическая сборка

```sh
npm run typecheck
npm run lint
npm run test
npm run format:check
npm run build
npm run test:smoke
```

Smoke запускает `dist/` через `npm run preview -- --port 4173 --strictPort`, поэтому сначала нужен build. По умолчанию используется Playwright Chromium; если его нет, установите `npx playwright install chromium` либо используйте установленный Chrome:

```sh
PLAYWRIGHT_CHANNEL=chrome npm run test:smoke
```

Фактически прошли 23 unit/integration-проверки и 1 browser smoke в Chrome; подробности, окружение и предыдущие ошибки — в отчёте. `npm run format` форматирует код и конфиги; принятые Markdown-документы и референсы исключены из автоматического переформатирования. `npm run test:watch` включает watch-режим. Сборка в `dist/` локальная, не означает публикацию. Для её ручного просмотра: `npm run preview -- --port 4173 --strictPort`.
