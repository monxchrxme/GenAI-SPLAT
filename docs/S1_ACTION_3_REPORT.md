## Результат

- N слотов размещаются через равные интервалы **вдоль длины** полилинии, включая оба конца при N≥2. Для одного агента — середина по длине. Дубли соседних точек безопасно пропускаются; пустые/короткие/вырожденные/нечисловые/слишком длинные линии отклоняются.
- Агент закреплён за одним индексом слота по числовому порядку Agent ID; текущие координаты и порядок agentIds не влияют на назначение. Повторная/обратная линия меняет места, но не ID → индекс. Это способ [P], не оптимизация кратчайших перемещений.
- На линии видны 40 полых целевых кружков. Во время drag это предварительный расчёт; на release Input отправляет set-formation с Group ID и копией полилинии → Session замораживает payload и ставит tick → Simulation валидирует/сохраняет план → detached frozen Snapshot → Renderer/HUD. Рендер не меняет state.
- Группа хранит formation.points и slots (Agent ID, индекс, x/y). Проверяются полное соответствие членству, уникальность и допустимость координат. Невалидный приказ не перезаписывает прежний план. Пустой клик очищает выбор/план, Restart очищает планы/очередь/журнал. Отмена черновика сохраняет прежний план.
- **Агенты не двигаются:** x/y/vx/vy и членство не меняются; слоты пока только назначения. Нет soft separation/натяжения/split и будущих механизмов. На очень короткой линии кружки могут перекрываться; равномерность считается по длине, минимальный физический интервал не вводился.

Радиус целевого кружка 3 CSS px, stroke 1.25 CSS px — типизированный presentation [P]. Цвет/контраст и правила назначения ожидают оценки пользователя. D-06 Open, D-07—D-10 Proposed; финальные спрайты S6.
