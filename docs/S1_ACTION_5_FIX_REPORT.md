## Причина и исправление

Сбой воспроизведён в Chrome при viewport 446×760: после выбора группы высота canvas менялась с 643 до 634 CSS px из-за переноса текста подсказки. Любой ResizeObserver callback отменял drag, поэтому изменение подсказки могло сместить поле, сбросить линию и оставить прежний приказ. В первоначальном регрессионном тесте boundingBox после выбора отличался от исходного; тест завершился exit 1. Это воспроизведение продуктового дефекта.

- Нижняя панель теперь резервирует постоянную высоту: 64 CSS px на desktop и 92 в узком окне. Длинный текст ограничен внутри панели; состояние подсказки не меняет геометрию поля. ResizeObserver отменяет жест только при фактическом изменении размеров арены, не при первоначальном callback с прежними размерами.
- Группа фиксируется на pointerdown. Валидируемая команда select-group-id (или null для очистки) проходит через Session/fixed step, без прямой записи из Input. Движущийся агент не должен успевать уйти из повторного hit test, а пустой клик не превращается в выбор агента, который подошёл во время нажатия. Pending-выбор учитывается для следующего быстрого жеста до публикации tick.
- Drag теперь можно начать и на синем маркере: короткий клик выбирает, протяжённый жест рисует для зафиксированной группы. Это уточнение UX [P] в рамках исправления быстрого ввода, показано для ручной оценки. Release сохраняет приказ именно группе, захваченной в начале жеста.
- Запоздалый lostpointercapture не отменяет уже захваченный новый жест; pointercancel фильтруется по текущему pointer ID. На обычный Esc/resize/выход за мир правила отмены сохранены.
- Завершённая линия и её слоты читаются из одного опубликованного snapshot с агентами/выбором. Локальный завершённый черновик не выдаётся за принятый приказ и не исчезает отдельным кадром до применения команды. Во время нового drag отображается его превью; отмена возвращает опубликованный план.
- Натяжение видно **во время drag**, если целевые промежутки превышают прежний порог. Текст о лимите и текст натяжения могут отображаться одновременно. На release остаётся прежний временный сигнал на 90 fixed ticks. Порог 48, длительность, maxLength 3200 и maxPoints 256 не увеличены и не отменены. Лимит линии и натяжение — разные состояния; компактный многократно изломанный рисунок не обязан вызывать натяжение только из-за лимита.

Натяжение остаётся визуальным, без изменения движения/численности/членства и без автоматического split. D-06 Open, D-07—D-10 Proposed. Исправления ввода не являются приёмкой S1 или утверждением новых способов split.
