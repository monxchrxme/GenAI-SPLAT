## Поведение действия 1

- ЛКМ по любому живому синему маркеру выбирает всю его группу; на текущей сцене выделяются все 40. В существующей нижней подсказке появляется «Выбрана группа · 40 Сплатов».
- Вокруг выбранных маркеров видны статичные бирюзовые кольца, отдельные от графики самих юнитов. Форма, размер, поворот и позиции юнитов не меняются, частиц/анимации нет.
- Клик по пустой области мира снимает выбор. Клик по полям вокруг вписанного мира (letterbox), правая кнопка и вторичный указатель игнорируются. Выделение происходит на ближайшем fixed tick после pointerdown.
- Client/CSS-координаты переводятся в world по фактическому прямоугольнику canvas и текущему логическому viewport. Учтены смещение canvas, масштаб CSS, resize и DPR без использования backing-buffer пикселей.
- Input отправляет intent → Session копирует/замораживает payload и ставит tick → Simulation детерминированно выбирает группу → frozen Snapshot → Renderer/HUD. Равные расстояния разрешаются по стабильному Agent ID. Renderer не пишет в simulation.
- Restart пересоздаёт сессию с `selectedGroupId: null`, очищает очередь, журнал и дробное время; последующие старые клики не выбирают группу заново.

Это UX-прототип [P], не утверждение D-07/D-10. Hit radius 16 world units, дополнительный радиус кольца 5 world units и толщина 1.5 CSS px находятся в типизированных конфигурациях. Клик по пустому полю как способ снять выбор также [P]; ввод drag в следующем действии потребует отдельной оценки управления. D-06 Open, автоматического split нет.
