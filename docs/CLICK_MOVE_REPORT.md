# Передвижение выбранной группы кликом — 10.11.2026

## Реализовано

По запросу заказчика клик по свободному месту при выбранной синей группе задаёт новое направление: на очередном фиксированном тике текущие координаты всех живых участников переносятся относительно их общего центра к указанной точке. У каждого сохраняется своё смещение, ID и членство; выделение остаётся. Это цель для обычного существующего движения: при обходе препятствий и взаимном расхождении форма по пути не обязана быть жёсткой. Форма на момент применения приказа может незначительно отличаться от момента события на экране.

Клик по другой группе переключает выбор, рисование линии задаёт новое построение, режим объединения сохраняет отдельное действие; после выделения красных пустой клик не отдаёт им приказ. При клике на препятствие либо когда хотя бы один конечный слот попадает на препятствие или за границу поля приказ отклоняется целиком, прежнее движение/выделение сохраняется, HUD показывает причину. Нет автоматического подбора свободной позиции. Новый валидный приказ участнику отменяет его активное объединение, как и нарисованный приказ. Если группа не выбрана или игра завершена, пустой клик не меняет симуляцию.

Это явно изменяет прежнее принятое поведение пустого клика — снятие выделения и остановку. Новое указание заказчика имеет приоритет; исторические записи и MASTER_SPEC не переписывались. Прежние API-команды явного снятия выделения сохранены для повторения старых журналов, но пустой клик больше их не отправляет. Новый тип приказа сохраняется в журнале с копией координат и воспроизводится детерминированно.
