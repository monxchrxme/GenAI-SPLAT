## Общие вход и выход этапа

**Definition of Ready:** согласованы цель, файловые границы, наблюдаемое поведение, данные и исключения, конфигурируемые гипотезы, тесты и способ запуска. Перед работой читать AGENTS, MASTER_SPEC, PLAN, STATUS, DECISIONS, ARCHITECTURE, DESIGN_GUIDE, SPEC и QA; проверять фактические файлы.

**Definition of Done для S0–S7:** код и необходимые тесты; успешные typecheck/lint/build; соблюдение инвариантов и смежной регрессии; ручное демо и приёмка человеком; актуальные README, STATUS, DECISIONS и CHANGELOG. Если проверка недоступна, указать команду и причину, не считать её успешной. Для S−1 применим только документальный гейт ниже, без игровых тестов.

После работы раздельно фиксировать `implemented`, `tests_verified`, `awaiting_manual_acceptance`; статус `accepted` — только по явной приёмке. После неё фиксировать стабильный commit при наличии Git; `main` содержит принятый результат, ветки по возможности `feature/sN-name`. Не утверждать публикацию без push. Handoff — 5–10 строк с фактами, проверками, ограничениями, решениями и следующим разрешённым действием.
