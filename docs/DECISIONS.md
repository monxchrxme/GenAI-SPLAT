## 2026-11-06 — OBS-07: первичный deployment Vercel

При подготовке ручной инструкции проверена [официальная документация](https://vercel.com/docs/deployments/environments#first-deployment): первый deployment нового проекта всегда Production, даже при `--target=preview` или feature-ветке. Это уточняет прежнюю инструкцию, которая не обеспечивала обещанный preview-only путь. Граница проекта сохраняется: агент ничего не публиковал, production-исключение пользователем не разрешено. Минимальный вариант **Proposed [P]** для отдельного решения: первичный технический Production deployment с `--prod --skip-domain` без автоматического назначения доменов, затем отдельный настоящий Preview; skip-domain не делает deployment приватным. При сохранении полного запрета Production до S7 гейт остаётся открытым. Последствия: DEPLOYMENT/STATUS уточнены, MASTER_SPEC и код не изменены, продуктовые Open/Proposed не закрыты.
